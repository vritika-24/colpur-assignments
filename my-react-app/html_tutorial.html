HTML Tutorial

Learn HTML

HTML is used to create the structure of web pages.

Introduction to HTML

HTML stands for HyperText Markup Language. It is the standard language used to create web pages.

HTML Topics

HTML Headings

Headings are created using h1 to h6 tags.

HTML Paragraphs

The p tag is used to create paragraphs.

HTML Links

The a tag is used to create hyperlinks.

HTML Images

The img tag is used to display images.

HTML Lists

HTML provides ordered and unordered lists.

HTML Tables

Tables are used to display data in rows and columns.

Basic HTML Example

<!DOCTYPE html>
<html>
<head>
    <title>My Website</title>
</head>

<body>
    <h1>Hello World</h1>
    <p>This is my first web page.</p>
</body>
</html>
